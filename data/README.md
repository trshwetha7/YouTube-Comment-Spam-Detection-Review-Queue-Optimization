# Data Notes

This project uses the public UCI YouTube Spam Collection.

- Source: https://archive.ics.uci.edu/dataset/380/youtube+spam+collection
- Raw files live in [`raw/`](/Users/trshwetha7/Desktop/Youtube-project/data/raw)
- Processed feature table is generated into [`processed/youtube_spam_processed.csv`](/Users/trshwetha7/Desktop/Youtube-project/data/processed/youtube_spam_processed.csv)

The public dataset contains 1,956 comments collected across five videos and only binary `spam` / `ham` labels. It should be treated as a prototype dataset for moderation triage experiments, not as production-grade moderation truth.
